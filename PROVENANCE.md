# Source provenance

This repository began as a clean copy of `exchange/` from the already-public [`HoneyMesh-Open-Source`](https://github.com/Smccann01/HoneyMesh-Open-Source/tree/20e5bfc8ee91e886beee2a8f4e80335b8355e84e/exchange) repository at commit `20e5bfc8ee91e886beee2a8f4e80335b8355e84e` (2026-11-22 audit). The source files retain their AGPL-3.0-only license.

The first dedicated-repository commit changes project naming and links, adds standalone setup and CI documentation, and removes old download material that was unrelated to a private Exchange. It does not copy Network Decode's newer hosted billing code from the private HoneyMesh 2.0 monorepo.

This repository starts a new Git history so an unrelated monorepo history is not republished. The link above identifies the public upstream revision for audit and attribution.
